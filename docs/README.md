# Documentation

Traze is a developer-run Hemi–Bitcoin publication explorer. Start with the guide
for your task. Public hosting and sustained operation remain validation work.

## Use the explorer

- [Quickstart](QUICKSTART.md): clone, run, search and inspect a result.
- [Search behavior and limits](SEARCH_GUIDE.md): stored evidence, public-source
  discovery, continuation, resource controls and historical examples.
- [Serving modes](SERVING.md): indexed-only reads and developer discovery.
- [Publication timeline](TIMELINE.md): browse indexed keystones and publications.
- [Terminology](GLOSSARY.md): records, status labels, coverage and verification.
