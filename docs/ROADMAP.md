# Roadmap

Updated October 14, 2026. Traze currently runs as a local prototype with an opt-in finite collector.

| Phase | Status | Intended outcome |
| --- | --- | --- |
| 1. Reusable Evidence Foundation | Complete within retained-data scope | Compiled publication records and correctly bound portable proof packets |
| 2. Demo Readiness and Production Plan | Complete within local-demo/planning scope | Reproducible demonstration, portable setup and a measured service plan |
| 3. Maintained Service Pilot | In progress; initial finite pilot validated | Automatic collection, checked associations, incremental indexing and durable recovery with measured operating costs |
| 4. Supported Public Beta | Not started | Hosted explorer, basic browsing, stable record links and supported read API within declared coverage and operating limits |
| 5. Selected Improvements and Expansion | Not started | Finite additions based on validated needs and feasible data |

Current source hosting and CI support reproducible development. Maintained collection and a public service still require the pilot and beta work below.

The current UI, Python parser/verifier and SQLite catalogue are reusable foundations. A finite collector now adds required Hemi metadata, incremental updates, durable live jobs and source/coverage observations. Indexed reads remain available during collection. These foundations still need sustained source-capacity, freshness and operating-envelope validation before public service release.

The pilot will measure update reliability, restart recovery, search performance, resource use and developer task outcomes within declared coverage. Those measurements determine the supported beta scope.

Possible later additions include wider history, publication monitoring, integrations, stronger earliest-publication assurance, independent finality recalculation and fee/reward analytics. They are not all prerequisites for the initial beta.

Maintenance continues after selected expansion work finishes.
