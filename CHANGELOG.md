# Changelog

## Snapshot-bound conditional assessment

- Add a version-3 wrapper around unchanged history/interval evidence with exact
  query, publication, anchor, source-view and snapshot-domain bindings.
- Require both a separately selected policy and canonical context checksum for
  the conditional claim; preserve older packet and policy meanings.
- Show the recorded domain and external historical-profile/source premises in
  the website and copyable summary, with matching portable verification/export.
- Keep missing, contradictory, unsupported and unaccepted context distinct from
  ordinary publication evidence. Retain the false unqualified global-proof flag.
- Include an optional public mainnet packet for offline reproduction. Website
  discovery does not automatically prepare or accept snapshot context for other
  inputs. Public hosting and sustained operating readiness remain separate work.

## Evidence presentation and distribution checks

- Clear a previous record URL before a new indexed query, including queries without indexed evidence.
- Keep the publication route prominent, with on-demand record inspection, verification details and per-block coverage. Preserve visible warnings, scan range, stopping reason and conditional assessment qualifications.
- Distinguish scan gaps, unresolved publication associations and unsupported payloads. Move collector diagnostics and implementation-level API limits into disclosures.
- Record preparation time for new verification packets separately from ordinary receipt/source times; preserve existing snapshot timestamps.
- Include the required standalone Python verifier in the selected distribution and check startup imports without network access or fallback to excluded workspace modules.

## Hosting preparation

- Add an optional production WSGI read adapter with exact-origin admission,
  bounded HTTP handling, safe browser configuration and no developer/source routes.
- Add local health/observation/accounting monitoring, proxy/process templates,
  quiesced state backup and verified fresh-target restore with acquisition interlock.
- Distinguish hosted-candidate browser content from local saved-file/operator
  diagnostics. Document operating procedures, hosting options and pending real-host gates.
